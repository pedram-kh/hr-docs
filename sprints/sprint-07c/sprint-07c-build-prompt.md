## The three tested invariants (non-negotiable — build + TEST)

1. **Only `verified` facts answer (the safety spine of all 7b connecting to chat).** The reference-fact path is reachable, and a fact is quoted, **only** when `status = 'verified'`. A `needs_review`/`rejected`/out-of-validity/future-only fact is **never** quoted — it escalates `reference_fact_coverage_gap`. **Test hardest:** the same question for a `needs_review`-fact scope must NOT answer from the fact. A bug here undoes all of 7b's inert-until-verified safety.
2. **Skip-ground (P1) vs must-ground (P2) — enforced by which path builds the answer, not a flag.** **Phase 1 quotes a verified value → skips `/ground`** (nothing generated to entail, exactly as salary skips it). **Phase 2 generates a composed answer → must `/ground`** (each substantive claim entailed against its cited source — fact's claim vs the fact, prose claim vs its chunk). The line is "did we quote a value or generate prose." **Test both:** a P1 turn has no grounding block; a P2 turn has a full per-claim grounding verdict.
3. **The convenio always governs — `structured_reference` below `official_convenio`; same-point conflict escalates, never blends.** A fact never overrides the law. In P2 the fact enters the source list at `structured_reference`, ordered below convenio by the existing precedence rule; a genuine fact-vs-convenio conflict on the same point → escalate, never blend or silently prefer the fact (the no-silent-override spine).
