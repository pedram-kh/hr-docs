## Confirmed design decisions (from the reality check)

- **`POST /compare-scope` — one additive, read-only, SELECT-only hr-ai endpoint** with the `authority_level` filter **in the SQL**, so the block decision is **k-independent** (the best eligible `official_convenio` chunk is rank 1 of an exactly-filtered, exactly-ordered set; no `k` can hide it). No LLM, no write, no migration. The `/sandbox-retrieve`-per-document loop stays recorded as the zero-hr-ai-change fallback, not built.
- **The draft has no chunks at fence time** → embed `resolution_text` as the query, **multi-probe** (paragraph-split so the embedder's truncation can't leave a tail uncompared), **max-over-probes** (which also makes the fence stricter).
- **Block thresholds are code config only (`config/hr.php`), NOT exposed in the guardrails UI.** ADR-0019's `max(floor, admin)` is wrong for a block-triggering similarity threshold (lowering blocks *more*); wiring it through `maxFloor` would let an admin loosen the fence. **Record in ADR-0024: any future admin exposure of a block-triggering similarity threshold must be `min(baseline, admin)`, not `max`.** Exposure is a Sprint-6-family follow-up.
- **Fence = `existing_block OR semantic_block`, structurally**: `detectConflicts` is not edited/narrowed/conditioned; the semantic pass is consulted **only** when it returns empty, so it can only turn ALLOW→BLOCK. No added latency on the common (already-blocked) path.
- **Two bands:** `semantic_conflict_threshold` → 409 `publish_blocked` reason `semantic_overlap` (open `conflict` task, card → In Progress, `escalation_events.detail.matches` = chunk ids + scores); `semantic_review_band` → 409 `publish_requires_acknowledgement` showing the near-passages, draft untouched, zero chunks written; re-POST with `acknowledge_semantic_overlap = true` → publishes + records `publish_acknowledged_overlap` with scores. **Compare failure → the acknowledge path with `semantic_compare_unavailable`, never a clean publish.**
- **§8.5 reverse re-check at the flag-only minimum bar**, reusing the existing `conflict` review-task type (no enum rewrite). First deferral candidate if it balloons — say so plainly in review.md if deferred.
- **(B) Duplicate pass = deterministic group-digit-token overlap** on same-convenio+topic facts (no embeddings, no threshold): `{1,2} ∩ {2}` surfaces the documented Navarra Intervención Social version pair as a **flag**. Resolution surface with **supersede** (older's `validity_end = newer.validity_start − 1 day`, both kept `verified`, lineage recorded — **never delete**), **coexist**, **reject** (existing status); each append-only `tag_events`. Resolved data reaches the 7c answer rule **through data only**.
- **(C) Succession = no LLM.** `successor` requires **both** high overlap (via `/compare-scope` with the expiring doc's chunk texts as probes) **and** strictly-later validity — a conjunction keeping the one dangerous label behind two independent conditions; works with no answer-model key. `coexisting_sibling` = low overlap same convenio; `conflict` = high overlap, not strictly-later validity. **Same-convenio candidates only.** Persisted as an inert `ai_agent` proposal on the expiry task (fuchsia); human confirm runs the existing 7a write-side; **the AI never writes `predecessor_document_id` or `retrieval_status`; the predecessor is never auto-retired.**
- **Three additive nullable migrations, no CHECK rewrite** (as listed in plan §6).

## Q1 resolved — calibration: real distribution + synthetic labeled anchoring, BOTH mandatory

Step 0 is a **hard prerequisite** before any threshold is chosen ("an unmeasured threshold on a safety gate is worse than the blunt fence"). Do both, in this order, and paste the full output into `review.md`:

1. **Real distribution.** `php artisan fence:calibrate-semantic` (read-only, writes nothing): run `/compare-scope` for **every already-published `internal_hr_ruling`** against its convenio's active `official_convenio` chunks; report per-ruling max / p90 / median and the block/acknowledge counts at candidate threshold pairs. Small N is fine — it shows the *shape* from real rulings.
2. **Synthetic labeled anchoring — always, not a fallback.** Take real active `official_convenio` chunks from several convenios and, for each, generate three probes with a **known** relationship: (a) a near-verbatim paraphrase of the chunk (a true same-point overlap → anchors the **block** threshold), (b) a same-topic-but-different-point passage (→ anchors the **acknowledge** band), (c) an unrelated passage (→ the floor). Run each through `/compare-scope` against its scope. Because the true relationship is known, these are **labeled** anchors the real rulings can't provide. Generate the paraphrases deterministically or by hand (a handful per class is enough; record them as fixtures in `sprint-07d/eval/`).
3. **Set thresholds conservatively from the union:** `semantic_conflict_threshold` sits **below** the lowest score any known-true-overlap (class a) produced — so no genuine overlap escapes; `semantic_review_band` catches the class-(b) region. **Err toward blocking more.** Report the chosen values with the anchor scores that justify them.
