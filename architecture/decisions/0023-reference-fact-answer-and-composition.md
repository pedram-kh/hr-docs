# ADR-0023 — The reference-fact answer + the fact·convenio-prose composition (the one sprint that touches the frozen 2b loop)

**Status:** accepted (Sprint 7c)

## Context

Sprints 0–7b built the answer engine (the frozen 2b loop) and the full **Structured Reference Knowledge** type — the `reference_facts` substrate (ADR-0021), the manual create/verify path, and the AI segmentation agent (ADR-0022) — but **nothing taught the answer loop to query `reference_facts`** (ADR-0022 §Consequences: *"No answering-from-facts (7c); 2b frozen"*). A proposed-and-verified fact was, by design, **not yet answerable**.

Sprint **7c** lifts that gate: a `verified` reference fact becomes **answerable** in chat and **composable** with governing convenio prose. This is the **one** sprint that touches the frozen 2b loop, so the whole discipline is **additivity** — prose and salary turns must stay **byte-for-byte unchanged**.

The loop **already** answers from an exact-structured path (`SalaryAnswerService`, SQL, ADR-0006) beside the vector prose path (`/retrieve`·`/synthesise`·`/ground`, ADR-0015). `reference_facts` was deliberately built to mirror the salary schema (data-model §6). So the reference-fact answer is a **clean parallel** beside salary — a new routed branch reusing the same shapes (the `chunk_id=null` citation, the structured-grounded skip-`/ground`, the distinct coverage-gap reason, the `floor_decision.path` trace), touching **no** salary/prose internal.

This sits beside **ADR-0006** (salary SQL path), **ADR-0015** (external answer model, abstain-not-fabricate, the `/ground` gate), **ADR-0016** (the question router + the deterministic salary pre-classifier, fail-safe to prose), **ADR-0020** (AI proposals inert until a human verifies), and **ADR-0021** (the substrate + the structurally-bounded `structured_reference` authority floor).

The danger to foreclose, by construction: a turn that quotes an **unverified / out-of-validity / future-only / mis-scoped** fact (undoing all of 7b's safety spine), a composed answer that lets the **lower-authority fact override the governing convenio**, and any change that makes a prose/salary turn diverge from today.

## Decision

Build 7c as **one sprint in two internal phases under one review**, in strict order. **Phase 1** is the routed reference-fact answer (the salary parallel; lands first and clean, committed before Phase 2). **Phase 2** is the fact·convenio-prose merge (composes on top; deferrable without leaving Phase 1 half-built). Both are **purely additive**: a turn takes a 7c path **only** when a `verified` reference fact in the asker's scope matches the question's topic — until 7c no fact was answerable, so today no turn takes the branch, and every non-reference-fact turn is unchanged by construction.

### Phase 1 — the routed reference-fact answer (the salary sibling)

1. **The deterministic pre-check (the salary-pre-classifier slot; no LLM, fail-safe).** A new deterministic step (`ReferenceFactRouter`) in the same layer as the salary pre-classifier — after the guardrail baseline, **only on a non-salary question** (the salary pre-classifier wins first; the two structured paths never contend), before the LLM router. It anchors the **question** against the **existing** topic lexicon (the same anchors the precedence re-rank uses — `vacaciones`, `jornada`, `permisos`, `periodo de prueba`, …), maps a matched anchor to an **approved** `topics` row by name, and asks whether a `verified`, in-scope, in-validity fact **exists**. No match / any ambiguity / any error → **fall through** to today's path. The pre-check can only ever *add* a route; it can never suppress or alter today's routing (the byte-for-byte guarantee at the routing layer). `TOPIC_ANCHORS` is lifted from a `ChatService` private const into a shared read-only `TopicLexicon` — a **pure relocation**, re-rank behavior unchanged (proven by the golden-trace regression).

2. **`ReferenceFactAnswerService` (mirrors `SalaryAnswerService` exactly).** Given resolved scope + matched `topic_id` + as-of: query `reference_facts WHERE convenio_id = … AND topic_id = … AND status = 'verified' AND (validity_start IS NULL OR ≤ as-of) AND (validity_end IS NULL OR ≥ as-of)`; answer the exact `value` (+ a `raw_values` breakdown) **verbatim, never paraphrased**; cite `source_document_id` with **`chunk_id = null`** (the salary citation shape, marked `is_reference_fact`); record `authority_used = structured_reference`; **skip `/ground`** (a quoted verified value — nothing generated to entail).

3. **Only verified answers — the non-negotiable safety spine (ADR-0020/0021).** `status = 'verified'` is the only gate that lifts. An unverified / `rejected` / out-of-validity / **future-only** fact is **never** quoted — the turn escalates a **distinct** `reference_fact_coverage_gap` (the `salary_coverage_gap` precedent), never `low_confidence`, never a guess. This is tested hardest.

4. **Scope resolution — most-specific, ELSE ESCALATE, never guess (Q2).** Prefer the employee's `job_category_id` (finest), else a **confidently-resolved** `group_label` (the fact's free-text label must name the employee's group code as a standalone token), else the convenio-wide fact (both null), else **escalate**. A confidently mis-scoped answer is the exact 7b-2 failure mode; a coverage-gap escalation is the safe outcome.

5. **The two-verified-match safe rule (resolution is 7d).** Two verified facts in a tier → most-recent `validity_start` wins; a genuine same-validity / differing-value conflict **escalates**, never blends. Rich version resolution is Sprint 7d — Phase 1 ships only the deterministic safe rule.

6. **Phase 1 is independently shippable.** It introduces **no** call to `/synthesise`/`/ground` and **no** change to their shapes, so it is committed clean before Phase 2 begins and is the deliberate fallback if the merge proves too delicate.

### Phase 2 — the fact·convenio-prose merge (reuse `/synthesise`+`/ground`, never rewrite)

7. **Composition detection extends the pre-check — it adds no new classifier.** When the pre-check finds a verified fact AND the **existing** prose retrieval surfaces **governing convenio prose on the topic** (an `official_convenio`/`internal_hr_ruling` chunk carrying the topic anchor that clears the existing **Check A** retrieval floor — Q5), the turn composes; otherwise it stays Phase 1 (fact only, skip ground) or today's prose path (prose only) — both unchanged.

8. **One grounded answer, the convenio governing.** Hand `/synthesise` the convenio chunks at `official_convenio` **and** the fact as **one more typed, authority-labelled source** — `source_type = reference_fact`, `chunk_id = null`, `authority_level = structured_reference` — ordered **below** the convenio by the **existing** precedence rule. This is an **additive field** (Q7): `SynthesisChunk`/`GroundChunkBody` gain `chunk_id: int | None` + `source_type: str = "chunk"`; a prose-only turn sends no fact source and the payload is identical to today. `_AUTHORITY_RANK` gains `structured_reference` **between** `official_convenio`/`internal_hr_ruling` (rank 0) and `national_law` (now rank 2) — a fact can never outrank a convenio (the ADR-0021 bound).

9. **Same-point conflict → escalate, NEVER blend (the spine Phase 2 must not weaken).** A deterministic, conservative figure-level check (the fact's load-bearing figures vs the governing convenio chunks' figures on the **same unit**; a same-unit / different-value disagreement is a conflict) runs **before** `/synthesise`, so a conflicting turn escalates (`conflict`) and **never** reaches synthesis — it can never blend or silently prefer the lower-authority fact. (The entailment gate alone can't catch this: it would find the fact's figure entailed by the fact source and pass it.) This is the no-silent-override spine of the salary/Estatuto precedence and the Sprint-4 ruling gate.

10. **Phase 2 MUST `/ground` (the skip-ground line, drawn explicitly).** A composed answer is **generated** (combines/paraphrases across sources), so each substantive claim is entailed against **its** cited source — the fact's claim against the fact (`chunk_id = null`), a prose claim against its chunk. An ungrounded composition escalates `low_confidence`. The citation set = the fact (`chunk_id = null`) **and** the convenio chunks, emitted **in the model's citation order** so the in-text `[Fuente N]` markers stay 1:1 (§7 marker discipline). `floor_decision.path = "reference_fact_composition"` (distinct from P1's `"reference_fact"` and from `"salary_sql"`).

## Consequences

- **Additive migrations only (ADR-0007).** **One** schema migration in all of 7c: `reference_fact_coverage_gap` added to the `escalation_cards.reason` CHECK enum, pattern-identical to the salary one (introspect-drop-readd, working `down()`). **Phase 2 adds none** (a conflict escalation reuses the existing `conflict` reason). No new tables, no `reference_facts` schema change (7b built the columns 7c queries).
- **hr-ai: nothing in Phase 1; additive-only in Phase 2.** Phase 1 is a DB query + answer assembly in hr-backend, exactly like salary. Phase 2 adds the nullable `chunk_id` + `source_type` field to the `/synthesise` + `/ground` request shapes and the `structured_reference` rank/label — **no rewrite** of the synthesis / entailment / citation-mapping logic (it is reused as-is; the citation dedup key is made null-safe by keying a fact on `(source_type, document_id)` instead of a colliding `None`). hr-ai never migrates.
- **The frozen loop is provably unchanged.** A golden-trace regression test pins a representative prose turn (Navarra *vacaciones* → "37 días laborables", cited to the convenio chunk, never the Estatuto) and a salary turn to a pre-7c baseline — **byte-for-byte answer + full trace** — and asserts no `reference_fact` block is present (the pre-check falls through). It is a gate after Phase 1 **and** re-run after Phase 2; both green. The wider answer-loop suite (69 Feature tests) stays green.
- **Only-verified is re-proven, not rebuilt.** New 7c tests assert a `needs_review` / `rejected` / out-of-validity / future-only fact is never quoted (the route is not even reachable), an unresolved group escalates rather than guesses, and a same-validity conflict escalates. The composition tests assert the convenio governs, a same-point conflict escalates before synthesis (never blends), and an ungrounded composition escalates.
- **No conflict/version resolution (7d).** The two-verified safe rule and the same-point conflict check **escalate**; they never pick a winner, merge, or delete. Semantic version resolution remains Sprint 7d.
- **Scope discipline.** Composition is scoped to **fact + convenio-prose on a shared topic**. A salary+reference compound, or arbitrary multi-topic triples, stay escalate-with-note (the existing `cross_path` posture) — richer per-clause decomposition is a later follow-up.
- Cites ADR-0006 (salary SQL), ADR-0015 (`/synthesise`·`/ground`), ADR-0016 (router + salary pre-classifier + fail-safe), ADR-0020 (inert-until-verified), ADR-0021 (the `structured_reference` bound), ADR-0007 (hr-backend owns the decision + writes; hr-ai reads/returns).
